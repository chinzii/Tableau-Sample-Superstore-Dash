# Tableau-Sample-Superstore-Dash
# 📊 Superstore Sales Analysis Dashboard | Tableau

1. Project Title
**Superstore Sales & Profit Analysis Dashboard**

2. Short Description
An interactive Tableau dashboard built to analyze Superstore sales, profit, customer segments, and regional performance. The dashboard helps identify sales trends, compare regional performance, and understand which product categories contribute most to overall profitability.

 3. Tech Stack
- **Data Visualization:** Tableau
- **Data Preparation:** Microsoft Excel
- **Dataset Format:** Excel (.xlsx)
- **Key Analytical Areas:** Sales Analysis, Profitability Analysis, Regional Analysis, and Trend Analysis

 4. Data Source
The project uses the **Sample Superstore dataset**, provided in Excel format. The dataset contains information about orders, customers, products, sales, quantities, discounts, shipping modes, and profits across different regions.

Key columns used:
- Order Date and Ship Date
- Customer Segment
- Region, State, and City
- Category and Sub-Category
- Sales, Quantity, Discount, and Profit

 5. Features & Highlights
- **Sales Trend Analysis:** Track sales performance over time.
- **Regional Performance:** Compare sales across different regions and locations.
- **Customer Segment Analysis:** Understand sales distribution across customer segments.
- **Product Performance:** Analyze sales and profitability by category and sub-category.
- **Geographical Visualization:** Explore sales performance across locations using maps.
- **Interactive Dashboard:** Combine multiple visualizations to make data exploration easier and support data-driven decisions.

6. Problem Solved
Businesses need to understand which products, customer segments, and regions drive sales and profitability. Raw sales data makes it difficult to identify trends, compare performance, and recognize areas that need improvement.

This dashboard transforms raw Superstore data into meaningful visual insights, helping users identify high-performing regions and products, monitor sales trends, evaluate profitability, and make better business decisions.

 Key Learnings
- Developed interactive dashboards using Tableau.
- Practiced data visualization and exploratory data analysis.
- Improved understanding of sales KPIs and business performance metrics.
- Learned to communicate business insights through visual storytelling.



**Tools:** Tableau | Microsoft Excel | Data Visualization | Business Intelligence
